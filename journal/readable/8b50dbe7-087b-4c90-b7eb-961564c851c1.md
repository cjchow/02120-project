# What you learned today

**Commenting assumptions**
- 0.01 is the **dark limit**: sunlight can drop below it, but `np.clip` keeps `light` at 0. For example, trans = 0.005 gives light = 0.
- Every number needs a source or the word "assumed." You labeled `rates` (line 56) and the floor (line 67).

**Indexing and arrays**
- `range(n - 1)` gives 0 to n−2. The number you pass to `range` is never included.
- The last slot is index `n − 1`, also written `-1`. The loop never fills `prod[-1]`, so line 68 does. Without it, the last day would wrongly show 100% photosynthesis.
- A numpy array is a list built for math. It does math slot by slot (`array * 2` doubles every slot), while `list * 2` repeats the list.
- In a 2-D array, `web[i]` is a whole row (one day), and `web[i, 0]` is one cell (producers on day i).

**The food web (lines 65–67)**
- `food` = what each level eats: `[prod[i], producers, herbivores]`. Nothing eats predators.
- The gap `food − web[i]`: negative means the level shrinks, positive means it grows, and zero means it stays put.
- `rates` = how fast each level responds. Response time ≈ 1 ÷ rate: plankton about 1 month, herbivores about 6 months, predators about 2 years. So the crash, and later the recovery, runs bottom to top with delays.
- The change is multiplied by `web[i]` because more organisms means more births or deaths. At exactly 0, a level could never recover, which is why there's a floor.
- `np.maximum(x, 1e-4)` picks the bigger of the two, so it only acts below 1e-4. It can also **hide bugs**: a missing `dt` would give −6.66, which the floor would quietly turn into 1e-4.

**Euler's method and step size**
- Line 66 = tomorrow = today + (change per year) × dt. That's forward Euler, the same method as the temperature lines.
- Without `dt`, each day would get a whole year's change (365× too big).
- We use Euler instead of an exact calculus formula because the linked equations have no neat formula. Check 1 already shows Euler matches the exact answer in a simple case.
- **Convergence test:** you halved `DT_DAYS`, and the results changed by less than 1%, so a 1-day step is small enough. That's verification, not validation.
